Public station-area lookup, derived from [DataMeet Indian Railways](https://github.com/datameet/railways/blob/21aa4a02617bdf300cd65ee69d1a33998d7b694e/stations.json), CC0. This snapshot contains 8,697 unique codes with geographic coordinates inside the India bounding box. Some names and codes are historical. Confirm the meeting entrance on the map. Initial-letter shards index name words and station codes. These are places, never ride listings.
